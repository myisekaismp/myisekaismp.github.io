Guia de Comandos Customizados (KubeJS)

Este documento contém a documentação completa de todos os comandos customizados registrados via KubeJS no servidor. Os comandos estão divididos por categorias e incluem tanto comandos de barra (/) quanto comandos de chat (!).

1. Comandos Gerais (Gerais)

Disponíveis para todos os jogadores do servidor.

Comando Tipo Sintaxe Descrição
rolar / /rolar <dado> [modo] Rola um dado (opções: d2, d4, d6, d8, d10, d12, d20, d100). Use o modo silent para que o resultado apareça apenas para você.
top / /top <categoria> [pagina/buscar <player>] Exibe rankings globais. Categorias: mortes, tempovivo, tempototal, morteshora, distanciasolo, distanciaelytra, mobkills, playerkills, lootr.
nicknames / /nicknames Exibe a lista de todos os apelidos de RP dos jogadores online associados aos seus nomes de usuário reais.
deaths / /deaths Exibe o seu total de mortes e a sua vitalidade atual (percentual).
deaths (alvo) ! !deaths <user> Exibe o total de mortes e vitalidade de outro jogador online.
fome / /fome Define o nível de fome do jogador para 1 (usado estritamente para propósitos de Roleplay).
colors / /colors Lista todos os códigos de cor e estilo de chat do Minecraft (com prefixo §).
dimension / /dimension Exibe a dimensão em que você está atualmente.
position / /position Exibe suas coordenadas X, Y, Z exatas.
level / /level Exibe o seu nível MMORPG atual.
insomnia / /insomnia Exibe o tempo decorrido desde o seu último descanso e avisa se Phantoms podem spawnar.
lojas ! !lojas Lista todas as lojas registradas no sistema.
loja ! !loja <shopId> Lista todos os funcionários online associados a uma loja específica.
enfermeiros / /enfermeiros Lista todos os enfermeiros em serviço/online no momento.
batataquente / /batataquente Inicia o minigame "Batata Quente" se não houver um ativo.

2. Comandos de Nativos (Nativos)

Disponíveis para membros autorizados do grupo Nativo (NATIVOS_GROUP / tag nativo) ou Administradores.

Comando Tipo Sintaxe Descrição
nativo / /nativo Alterna a tag de nativo (entra/sai do modo nativo).
builder / /builder Alterna o modo construtor (permite quebrar blocos em áreas protegidas, altera para gamemode criativo e entra no time builder).
warp ! !warp Teleporta o jogador para a "base off rp" de nativos.
author ! !author <nome> Altera o autor do livro escrito que você está segurando na mão principal.
voucher ! !voucher Exibe um menu clicável para escolher e obter vouchers de itens exclusivos (Funil de Bambu, Biplano, Dirigível).
givevoucher ! !givevoucher <id> Concede diretamente o papel de voucher correspondente ao ID selecionado.
channel_nativo / /n <mensagem> Envia uma mensagem no canal de chat exclusivo de Nativos (visível para nativos e admins).

3. Comandos de Magias (Magias)

Disponíveis para magos autorizados (AUTHORIZED_PLAYERS_MAGIAS) ou Administradores.

Comando Tipo Sintaxe Descrição
silencio ! !silencio <player> Silencia o chat de voz (Simple Voice Chat) do jogador alvo.
fale ! !fale <player> Libera o chat de voz do jogador alvo.
conter ! !conter <player> Contém (prende/imobiliza) o jogador alvo.
liberar ! !liberar <player> Libera o jogador contido.
prisao ! !prisao <player> Envia o jogador contido diretamente para a dimensão de prisão.
revelio ! !revelio Conjura revelação, dando efeito de brilhar (glowing) para entidades próximas num raio de 15 blocos.
matinta / /matinta <colar/coruja/mimetismo/assobio/casa> [alvo] Gerencia e ativa habilidades exclusivas da Matinta (requer permissão ou ser Matinta autorizada). colar gera o pingente de sangue Botania vinculado ao alvo.

4. Comandos de Administradores (Admin)

Restritos a Administradores (equipe admin ou OP nível 2+).

Comando Tipo Sintaxe Descrição
track / /track <player/stop> Ativa ou desativa um overlay visual na tela mostrando a vida (HP) e o escudo (Magic Shield) do jogador alvo.
camera / /camera Liga/desliga o bloqueio global de uso do item de câmera.
clima / /clima <subcomando> Gerencia e agenda climas extremos. Subcomandos: status, sol, chuva, tempestade, acido, calor, peixe, slime, hamburguer, estacao, chance, previsao, agendar.
lastseen / /lastseen <dump/inactive> Gerencia dumps de atividade dos jogadores ou envia alertas de inatividade manualmente para o canal do Discord.
levels / niveis / /levels ou /niveis Exibe no chat a lista de níveis MMORPG de todos os jogadores online (Requer OP Nível 4).
persistentdata / /persistentdata <view/remove/set> <player> [key] [data] Visualiza, remove ou altera chaves e valores dos dados persistentes de NBT de um jogador.
rcdstorm / /rcdstorm <toggle/chance> Ativa ou altera a chance do evento de Tempestade Infinita (Enhanced Lightning).
toggledeathmsg / /toggledeathmsg Alterna a exibição global de mensagens de morte de roleplay.
channel_admin / /a <mensagem> Envia uma mensagem no canal de chat restrito da Staff/Admin.
xp ! !xp Lista os jogadores online ordenados pela experiência (XP) MMORPG atual.
op ! !op Insere o próprio administrador na equipe admin e concede OP nativo no Minecraft.
deop ! !deop Remove o próprio de OP e o retira da equipe admin.
resetinsomnia / /resetInsomnia Reseta o temporizador de insônia do próprio jogador (ou reseta o seu próprio se usado sem argumentos).
flu ! !flu <user> Infecta manualmente o jogador especificado com gripe comum.
cureflu ! !cureflu <user> Cura manualmente a gripe do jogador especificado.
infect ! !infect <user> Infecta o jogador especificado com Febre do Abismo (doença do End).
cure ! !cure <user> Cura o jogador especificado da Febre do Abismo (doença do End).
feridos / /feridos Lista todos os jogadores infectados ou feridos online (acessível também a enfermeiros).
cmd ! !cmd <target> Executa comandos de teste de administração.
send ! !send <msg> Cancelador de chat para testes de mensagens de nativos por admins.
